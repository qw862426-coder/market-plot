Privacy Policy

Effective date: October 19, 2026

This policy covers "stock-shorts uploader" (the "App"), a private tool operated by the owner of the Market Plot YouTube channel. The App's only purpose is to upload videos and caption files to the owner's own YouTube channel.

Who uses the App

Only the channel owner. The App is not offered to the public, and no one else signs in to it.

What data the App accesses

  • With the owner's permission, the App uses the YouTube API Services to upload videos, titles, descriptions, tags and caption files to the owner's channel.
  • It stores one authorization credential (an OAuth refresh token) as an encrypted secret in the owner's private GitHub repository, so uploads can run automatically.
  • It does not collect, read, sell or share personal data about viewers or any other person.

YouTube API Services

The App uses YouTube API Services. By using the App you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

The owner can revoke the App's access at any time on the Google security settings page. Revoking access stops all uploads. The stored credential is then deleted from the GitHub repository.
